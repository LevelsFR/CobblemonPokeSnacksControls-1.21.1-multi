# Cobblemon PokeSnacks Controls v2.2.1

## Changes

* Updated **OS Cobblemon Library** to **1.5.2** for the latest-spawn display and rare Pokémon alerts.

# Cobblemon PokeSnacks Controls v2.2

## New

* Added each snack’s latest successful Pokémon spawn to **Jade**, including its form, Shiny or Alpha status, and marks.
* Added optional alerts when a snack attracts a **Shiny, Alpha, or marked Pokémon**. Alerts are disabled by default.
* Added the admin command `/psc snack give <item-id> [item-id ...]` to create a native Poké Snack from up to **eight bait ingredients** and give it to yourself.

## Changes

* Updated the supported **Cobblemon** range to **1.8.2–1.8.x**.
* Required **OS Cobblemon Library 1.3.0+** on Fabric and NeoForge for Pokémon identity details.
